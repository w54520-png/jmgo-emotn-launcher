# Projector Home

This is an original, dependency-free Android home screen bundled with the Skill.
It enumerates installed launcher applications, supports remote focus navigation,
and exposes Android Settings. It is not a copy of EMOTN UI and contains no
EMOTN assets.

Build it with:

```bash
./build.sh
```

The resulting APK is copied to `../assets/projector-launcher.apk`.
